### Sobre

Engenheiro de software especializado em projetar e escalar sistemas empresariais críticos para **portos e logística**. Atuo no ecossistema **.NET**, com APIs de alta disponibilidade e camadas de dados em **Oracle** e **SQL Server**. Foco em resiliência de arquitetura, deploys sem downtime e transformar regras de negócio complexas em software que sustenta a continuidade operacional de terminais portuários.

Na **ModallPort** (mar/2024 — atual), lidero a evolução do software de operação: APIs de alto throughput, UIs modulares, faturamento, booking e monitoramento operacional.

### O que entrego

- Rastreamento de frota com dashboard de KPIs em tempo real e RBAC
- Motor de simulação de faturamento em .NET + Oracle, com menor latência de cálculo
- Locks de concorrência distribuída no pipeline de booking (sem cobrança duplicada)
- Framework de UI modular compartilhado por três aplicações (~30% menos tempo em módulos novos)
- Pacotes NuGet internos (GitLab Package Registry), RCA em produção e SQL/Oracle otimizados para relatórios
